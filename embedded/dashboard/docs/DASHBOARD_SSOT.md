## OpenFOAM 참고 영상 — 2026-10-22 적용

- 예시·실측의 **선택 팬 조합**에서 세 상황과 양쪽 PWM을 선택하면 해당 원본 영상을 바로 재생할 수 있습니다. 사전 계산 참고 자료이며 실시간 CFD·실측 기류·카메라 영상으로 표시하지 않습니다.

4. 명령 성공 후에만 온도 제어기에 최종 적용값을 알립니다. 화면 목표와 실제 PWM/RPM 피드백을 구분합니다.

## 값과 기록의 의미

BME280 온도·습도·기압, PMS5003 PM1/PM2.5/PM10, 팬 PWM/RPM을 실제 DATA에서 수신합니다. 미수신·오류·오래된 수치는 빈 값/대기로 표시합니다. CCTV는 현재 프레임을 조회하고 지연 시 숨깁니다. 온도 사건은 DB에서 날짜별 조회하고, 카메라 연기 사건은 서버 세션 메모리 최대 30건입니다.

전력은 팬별 `5 × 0.27 × (RPM / 7500)^3` W의 합이며 실제 RPM 기록으로 적분한 추정 에너지를 표시합니다. 표본 간격이 2.5초를 넘으면 제외합니다. PM 제어기의 가상 요구 에너지를 더하지 않습니다. 전력계 실측이 아닙니다.

Aiven 이상·회복 상세 화면은 PM2.5 사건에 PM2.5 회복 추이와 팬 합산 추정 전력(W), 온도 사건에 온도 회복 추이와 팬 합산 추정 전력(W)을 표시합니다. 복합·항목 미기록 사건은 두 센서 추이와 전력을 함께 표시합니다. 양쪽 RPM 중 하나라도 누락·오류이면 해당 전력은 빈 값으로 유지하며, RPM 미기록 과거 사건에 PWM이나 습도로 전력을 대신 계산하지 않습니다. 습도 원본 값은 측정 표본 표와 CSV에서 확인할 수 있습니다.

## PM 이벤트 추가 전달본

`fan_control_final_통합용 (1).zip`의 PM 이벤트 기록기·업로더를 반영했습니다. 제어기와 회귀 모델 내용은 기존과 같으며, 통합 최대값 정책·탭 연결 정지·에너지 계산을 유지합니다. 최초에는 로컬에만 반영했으며, 후속 사용자 요청으로 아래 Aiven 연동과 함께 실제 Jetson에 배포했습니다.
