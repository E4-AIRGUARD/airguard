# AIRGUARD 대시보드 SSOT

기준일: 2026-10-21 KST. 이 문서는 대시보드 통합의 현재 기준이며 전달 ZIP 내부의 예제·이전 실행 기록보다 우선합니다. 열 실험의 조건·절차는 기존 `THERMAL_EXPERIMENT_SSOT.md`가 관리하며 이 문서가 변경하지 않습니다.

## 제어의 우선순위

1. 활성 대시보드 연결이 없으면 흡기·배기 0/0. 센서와 카메라는 유지합니다.
2. 연결이 있으면 온도 v6 요구와 원시 PM2.5 요구의 **흡기별·배기별 최대값**을 전송합니다. 특정 센서 하나에 일률적인 우선순위를 주지 않습니다.
3. 온도 60/100, PM 100/60이면 최종 100/100. 카메라 연기 확률은 팬 제어 입력이 아닙니다.
4. 명령 성공 후에만 온도 제어기에 최종 적용값을 알립니다. 화면 목표와 실제 PWM/RPM 피드백을 구분합니다.

PM 정상 요구 35/35, PM 갱신 지연 10초 초과 또는 초기 유효값 없음은 모듈의 100/100 요구가 될 수 있습니다. 온도 유효값이 없을 때의 요구는 35/35입니다. 실제 부하에서 정책의 제어 성능은 별도 평가 대상입니다.

## 브라우저와 팬 수명

3초마다 탭 연결 신호를 보냅니다. 마지막 탭 닫기 통지를 받으면 정지하고, 통지를 놓치면 마지막 신호 후 15초에 연결이 만료됩니다. 다른 PC/탭이 연결되어 있으면 운전합니다. 독립 감시 스레드가 0/0을 전송하고 비활성 상태에서는 주기적으로 재전송합니다. RPM은 관성 때문에 이후 0에 도달합니다.

인증 키는 PC와 Jetson의 `runtime/dashboard_lease.key`에만 보관합니다. 키 없는 새 복제본은 조회용입니다. 팬을 활성화할 팀원에게 키를 별도 전달해야 합니다. 현재 센서 API CORS 출처는 `http://127.0.0.1:8091`입니다.

## 연기 소스와 실제 실행 버전 구분

- 실제 Jetson: motion-gate 수정본 + `--on 0.5`, `off=0.15`, 모델 `smoke_cls_v7_640.engine`.
- 저장소: `smoke_dashboard_link_v4.zip` 소스 반영, 기본 on=0.50/off=0.30. v4 모델은 ZIP에 없었습니다.
- 사용자 요청에 따라 v4 파일은 로컬에만 적용했으며 실제 Jetson의 연기 파일을 v4로 다시 교체하지 않았습니다. 신규 설치 예제는 기존 임계값을 유지하도록 `--off 0.15`를 명시합니다.
- motion gate는 영상 변화량을 확인하는 추가 조건입니다. 새 알림 시작에만 최근 3초 내 변화량 4.0 이상을 요구하고, 이미 시작된 알림은 모델 상태와 4초 해제 대기를 따릅니다.

## 값과 기록의 의미

BME280 온도·습도·기압, PMS5003 PM1/PM2.5/PM10, 팬 PWM/RPM을 실제 DATA에서 수신합니다. 미수신·오류·오래된 수치는 빈 값/대기로 표시합니다. CCTV는 현재 프레임을 조회하고 지연 시 숨깁니다. 온도 사건은 DB에서 날짜별 조회하고, 카메라 연기 사건은 서버 세션 메모리 최대 30건입니다.

전력은 팬별 `5 × 0.27 × (RPM / 7500)^3` W의 합이며 실제 RPM 기록으로 적분한 추정 에너지를 표시합니다. 표본 간격이 2.5초를 넘으면 제외합니다. PM 제어기의 가상 요구 에너지를 더하지 않습니다. 전력계 실측이 아닙니다.

## 검증 및 남은 범위

실장비에서 최신 센서·원본 CCTV·팬 PWM/RPM 수신, 탭 닫기 후 양 팬 PWM/RPM=0 연속 표본, 연결 신호 중단 후 약 18.2초 내 RPM=0, 다시 열기 후 자동 제어 복구를 확인했습니다. 소프트웨어 검사는 [작업 기록](WORK_LOG_20261021.md)을 참조합니다.

고온·연기 동시 부하에서의 감지 정확도/회복 성능, v4 연기 소스의 실장비 재검증, Jetson 강제 종료 시 하드웨어 정지, 재부팅 자동 실행은 완료 범위에 포함하지 않습니다.
