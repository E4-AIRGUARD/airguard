# 팬 모니터 대시보드

보여주는 것: 현재 PM2.5, 흡기/배기 팬 속도(35/60/100), 구간별 추정 에너지(현재 제어 / 약약 고정 35/35 / 강강 고정 100/100), PM·팬 조합 추이.

## 실행 (젯슨 또는 PC)
```
python3 serve_dashboard.py <에너지로그.csv> 8080     # 표준 라이브러리만 사용
브라우저: http://<젯슨IP>:8080          (같은 기기면 http://localhost:8080)
```
- 에너지 로그는 제어기의 `EnergyMeter`가 만드는 CSV(`time_s,pm,combo,power_w,energy_j,reason`)입니다. 제어 루프에서 `meter = EnergyMeter(planner, '에너지로그.csv')`로 열고 매 주기 `meter.update(d)`를 호출하면 한 줄씩 쌓입니다.
- 2초마다 로그 끝부분(최근 3600줄)을 다시 읽습니다. 로그가 커져도 파일 끝만 읽어서 가볍습니다.
- 서버 없이 `dashboard.html`을 그냥 열거나 `?demo`를 붙이면 샘플 데이터로 움직입니다(상단에 "데모 데이터" 표시). "로그 파일 열기"로 저장된 CSV를 직접 볼 수도 있습니다.
- 집계 구간(10분/1시간/전체)을 바꾸면 에너지 비교가 그 구간 기준으로 다시 계산됩니다. 약약·강강 값은 `전력 × 구간 시간`입니다(35/35 = 0.144 W, 100/100 = 2.083 W, RPM 기반 추정).
- 로그는 하루에 한 번 새 파일로 바꾸는 걸 권합니다(1초 간격이면 하루 약 5MB).
- `dashboard.template.html`은 샘플 로그를 넣기 전의 원본이고, `dashboard.html`은 샘플이 들어간 배포용입니다.
- 모델을 다시 만든 뒤에는 `python3 build_dashboard.py`로 `dashboard.html`의 "예상" 값(model.json 요약)을 갱신합니다.
- 에너지 비교는 가장 최근 "회복 구간"(PM이 50을 넘어 올라간 시점부터 PM20 이하 도달까지)을 찾아, 같은 출발 PM에서 9개 고정 조합을 끝까지 돌렸을 때의 예상 시간·에너지와 실제 제어 결과를 나란히 보여줍니다.
