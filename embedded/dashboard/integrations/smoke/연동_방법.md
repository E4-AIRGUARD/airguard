# 연기 감지 알림, 대시보드 연동 방법

## 전체 구조
```
카메라 → Jetson: smoke_alert.py (모델 판단 + 작은 웹 서버, 포트 8092)
                      ↑ 1초마다 가져감
         브라우저: 대시보드 + smoke-alert.js (배너·토스트·기록·연결 표시)
```
확인해 보니 대시보드(`embedded/dashboard`)는 HTML/JS만 있는 예시 모드 화면이고 장비와 통신하는 API가 아직 없었어요. 그래서 Jetson 쪽에 상태를 내주는 서버를 두고, 대시보드는 `app.js`를 고치지 않고 스크립트 파일 하나만 붙이는 방식으로 만들었어요.

## 1. Jetson에서 실행
필요한 것: 지금 쓰는 `ultralytics`, `opencv`만 있으면 돼요 (알림 서버는 표준 라이브러리). WebSocket 전송(`--ws-url`)을 쓸 때만 `websockets`가 필요해요.
```
cd ~/smoke
python3 smoke_alert.py --model smoke_cls_v4.pt --source 0 --device 0
```
- 켜기 기준 0.50, 끄기 기준 0.30 (v4), EMA 0.3, 유지 2초, 3프레임마다 판단, 카메라 180도 회전이 기본값이에요(위 최적화 결과 반영).
- 연기가 켜지고 꺼질 때 터미널에 `연기 감지` / `연기 해제`가 찍혀요.
- 영상 파일로 먼저 시험하려면 `--source cmp2_....mp4 --rotate 0 --realtime`.
- 끄기는 `Ctrl+C`.

주요 옵션
| 옵션 | 기본값 | 설명 |
|---|---|---|
| `--on`, `--off` | 0.50, 0.30 | 켜기/끄기 기준 |
| `--clear-sec` | 4 | 판정이 꺼진 뒤 이 시간 동안 다시 안 켜져야 "해제" 알림. 연기가 잠깐 옅어져도 알림이 껐다 켜지지 않게 함 |
| `--port` | 8092 | 알림 서버 포트 |
| `--post-url` | 없음 | 연기 켜짐/꺼짐 때 이 주소로 JSON을 POST (선택) |
| `--ws-url` | 없음 | 같은 JSON을 WebSocket으로 전송 (선택) |
| `--motion-gate` | 꺼짐 | 켜면, 새로 알림을 울릴 때 최근 3초 안에 화면에 움직임이 있어야 함. 가만히 놓인 모기향 오탐을 막기 위한 임시 방편 |
| `--motion-min` | 4.0 | 움직임 기준. 빈 화면은 약 2, 손이나 연기가 움직이면 약 5~30. 현재 값은 `/api/smoke`의 `motion`에서 볼 수 있음 |
| `--repeat-sec` | 0 | 연기가 계속되는 동안 N초마다 감지 알림을 다시 보냄 |
| `--device-id` | 호스트 이름 | 알림에 들어가는 장치 이름 |

서버 주소 확인: 같은 네트워크(또는 Tailscale)에서 브라우저로 `http://<Jetson 주소>:8092/api/smoke`가 열리는지 보세요. 안 열리면 방화벽이나 주소 문제예요.

## 2. 대시보드에 붙이기 (파일 2곳)
1. `smoke-alert.js`를 `embedded/dashboard/dist/`에 복사해요.
2. `embedded/dashboard/dist/index.html` 맨 아래 `app.js` 줄 바로 다음에 한 줄을 추가해요.
```html
<script src="app.js"></script>
<script src="smoke-alert.js"></script>
```
3. 대시보드를 열 때 알림 서버 주소를 한 번 붙여서 열어요 (이 브라우저에 저장돼요).
```
http://127.0.0.1:8091/?smoke=http://<Jetson 주소>:8092
```
주소를 지우려면 `?smoke=off`로 열어요. 주소가 없으면 스크립트는 아무것도 하지 않아서 기존 화면이 그대로예요.

보이는 것
| 상황 | 화면 |
|---|---|
| 연기 감지 | 화면 위 빨간 배너(시작 시각, 점수, 감지 순간 사진, 확인/소리 버튼), 토스트, "최근 알림·운전 기록"에 줄 추가 |
| 연기 해제 | 초록 배너(지속 시간)가 8초 보였다 사라지고 기록에 해제 줄 추가 |
| 평소 | 오른쪽 아래에 "연기 없음 · 점수 0.04" 연결 표시 (점수와 감지 표시는 즉시 판정이고, 알림 배너의 해제만 `--clear-sec`만큼 늦게 바뀜) |
| 서버 끊김 | "연기 알림 서버 연결 끊김", 카메라가 멈추면 "카메라 응답 없음" |

## 3. 알림 서버가 주는 데이터
`GET /api/smoke`
| 필드 | 뜻 |
|---|---|
| `smoke` | 지금 연기 알림 상태 (true/false) |
| `score`, `avg` | 현재 점수, 평균 점수 |
| `cameraOk`, `ageSec` | 카메라가 정상인지, 마지막 판단 후 지난 초 |
| `current` | 진행 중인 연기 기록 (없으면 null) |
| `incidents` | 최근 기록 30개, 최신이 먼저. 각각 `id`, `start`, `end`, `peak`, `durationSec` |

그 밖에 `GET /frame.jpg`(최근 카메라 사진), `GET /event/<id>.jpg`(감지 순간 사진). `--post-url`/`--ws-url`로 보내는 메시지 모양은 아래와 같아요.
```json
{"type":"SMOKE_ALERT","event":"SMOKE_DETECTED","deviceId":"jetson-03","incidentId":"SMOKE-20261021-151200-1",
 "time":"2026-10-21T15:12:00+09:00","score":0.98,"avg":0.41,"peak":0.98,"durationSec":null,"model":"smoke_cls_v4.pt"}
```
`event`는 `SMOKE_DETECTED` 또는 `SMOKE_CLEARED`예요. 이 메시지 모양은 제가 정한 것이라, 팀의 백엔드가 요구하는 모양이 따로 있으면 `smoke_alert.py`의 `event()` 함수 한 곳만 고치면 돼요.

## 4. 주의할 점
- **https 사이트에서는 못 읽어요.** README의 공개 사이트(https)에서는 브라우저가 `http://Jetson주소`로의 요청을 막아요. 시연은 로컬(`python run.py`, http)로 여는 것을 권해요. 공개 사이트에서 쓰려면 Jetson 쪽을 https로 바꿔야 해요.
- 알림 서버는 인증이 없고 아무 주소에서나 읽을 수 있게(CORS 전체 허용) 열려 있어요. 같은 네트워크 안에서 시연하는 용도예요. 외부에 공개하면 카메라 사진이 누구에게나 보여요.
- 대시보드의 다른 값(PM2.5, 팬 등)은 여전히 예시 데이터예요. 연기 알림 부분만 실제 값이에요.

## 5. 확인한 것과 못 한 것
| 항목 | 상태 |
|---|---|
| 영상 파일(cmp2 일부)로 감지·해제 판단, 상태 서버, 사진 두 종류, POST·WebSocket 전송 | 확인 (제 컨테이너 CPU, `.pt` 모델) |
| 대시보드 쪽: 가짜 서버로 배너, 토스트, 기록 줄, 확인 버튼, 해제 표시, 주소 저장 | 브라우저(Chromium)로 확인 |
| 기존 대시보드 검사(`node tests/dashboard.cjs`) | 통과 (`app.js`를 안 고쳤어요) |
| 실제 Jetson 카메라, TensorRT `.engine`, Jetson 네트워크에서의 실행 | **아직 못 해 봄**. 첫 시험은 사용자가 해 주셔야 해요 |
| 실제 연기를 피웠을 때 알림이 뜨는 시연 전체 | **아직 못 해 봄** |
| 소리 알림 | 코드만 있고 직접 들어보진 못함 (브라우저는 버튼을 눌러야 소리를 허용해요) |

## 6. 모기향 오탐과 `--motion-gate`
- 모델이 가만히 놓인(불 안 붙은) 모기향을 연기로 판단하는 경향이 남아 있어요. 연기는 움직이고 모기향은 가만히 있다는 차이를 이용한 임시 방편이 `--motion-gate`예요.
- 확인한 것: 연기가 있는 영상(cmp2)에서는 켜고 꺼도 감지가 똑같고, 영상 한 장을 계속 보여 줘서 점수가 0.99로 높게 나오는 "가만히 있는 장면"에서는 알림이 막혔어요.
- 못 한 것: 실제로 모기향을 놓은 장면에서는 시험하지 못했어요.
- 한계: 연기가 아주 옅고 거의 안 움직이면 알림이 안 켜질 수 있고, 손으로 모기향을 만지면 움직임이 생겨서 알림이 켜질 수 있어요.
