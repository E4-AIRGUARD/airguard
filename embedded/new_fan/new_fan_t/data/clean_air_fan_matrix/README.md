# 가열·연기 없는 팬 9조합 데이터

조합당 300초(5분), 총 45분, 사진 1초 간격.
실제 측정 시작 시 실행 시각 폴더가 생성됩니다.

- `<실행시각>/csv/<조합>/`: 고정 9컬럼 센서 CSV
- `<실행시각>/images/<조합>/<실행ID>/`: JPG, images.jsonl, run.json
- `<실행시각>/batch.json`: 전체 진행 상태와 완료한 조합

코드와 실행법: 상위 프로젝트의 CLEAN_AIR_EXPERIMENT.md.
카메라 저장 점검용 이미지는 `_camera_check/`에 두며 실험 데이터로 사용하지 않습니다.
