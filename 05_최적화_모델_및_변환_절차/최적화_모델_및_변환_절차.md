# TensorRT FP16 최적화 모델과 변환 절차

웹캠 연기 판별 모델(YOLO11n-cls)을 TensorRT FP16으로 변환한 결과와 변환 절차를 정리했습니다.

## 1. 목적과 방식

| 항목        | 내용                                                                                   |
| ----------- | -------------------------------------------------------------------------------------- |
| 목적        | Jetson Orin Nano에서 추론 속도와 전력 효율을 높임 (정확도는 유지)                      |
| 방식        | PyTorch 모델(`.pt`)을 TensorRT 엔진으로 변환하고, 연산 정밀도를 FP32에서 FP16으로 낮춤 |
| 대상 모델   | `smoke_cls_v4.pt` (YOLO11n-cls, 3.2MB) → `smoke_cls_v4.engine` (4.6MB)                 |
| 입력 / 출력 | `1x3x640x640` / `1x2` (smoke, no_smoke)                                                |
| 환경        | Jetson Orin Nano 7.6GB, TensorRT 10.3.0, torch 2.8.0, Ultralytics 8.4.118              |

## 2. 변환 과정

| 단계 | 하는 일                                                                                  | 소요            |
| ---- | ---------------------------------------------------------------------------------------- | --------------- |
| 1    | `.pt` 모델을 ONNX(5.9MB)로 내보냄                                                        | 약 2초          |
| 2    | 그래프를 최적화하고 FP16 TensorRT 엔진을 빌드 (이 기기에 맞는 연산 방식을 시험해서 선택) | 약 261초        |
| 3    | `.engine` 파일로 저장                                                                    | 약 267초 (전체) |
| 4    | 같은 영상으로 속도와 점수를 `.pt`와 비교해 검증                                          | -               |

실행 명령: `yolo export model=smoke_cls_v4.pt format=engine half=True imgsz=640` (측정은 `benchmarks/bench_speed.py`, 자세한 사용법은 README)

## 3. 결과 (Jetson Orin Nano, 입력 640, 600프레임, 2회 측정)

| 항목                         | `.pt`           | TensorRT FP16        | 변화                 |
| ---------------------------- | --------------- | -------------------- | -------------------- |
| 추론 시간 평균               | 36.14 / 35.14ms | 28.36 / 27.33ms      | -21.5% / -22.2%      |
| 전체 시간 평균 (전처리 포함) | 39.66 / 38.62ms | 31.85 / 30.82ms      | -19.7% / -20.2%      |
| 초당 프레임                  | 25.2 / 25.9     | 31.4 / 32.5          | +24.6% / +25.4%      |
| GPU 메모리                   | 62.7MB          | 9.4MB                | -85%                 |
| 전력 평균                    | 6.49W           | 5.66W                | -12.8%               |
| 프레임당 에너지              | 약 251mJ        | 약 174mJ             | -30%                 |
| 정확도 (cmp2 1309점)         | 기준            | 점수 차이 최대 0.003 | 판정 바뀐 프레임 0개 |

## 4. 해석

| 항목        | 내용                                                                                                                |
| ----------- | ------------------------------------------------------------------------------------------------------------------- |
| 속도        | 추론 시간이 약 20% 줄고 초당 프레임이 약 25% 늘었습니다. 전처리 3.5ms는 그대로입니다                                      |
| 정확도      | FP16 변환으로 인한 손실은 확인되지 않았습니다                                                                         |
| 전력        | GPU 사용률이 약 58%에서 33%로 줄었고 전력은 13% 낮아졌습니다                                                              |
| 실사용 의미 | 데모는 3프레임마다 한 번 판정하고 카메라가 약 10fps라서 `.pt`도 속도는 충분합니다. 손해 없는 개선이지만 필수는 아닙니다 |

## 5. 제약과 주의

| 항목           | 내용                                                                                                   |
| -------------- | ------------------------------------------------------------------------------------------------------ |
| 기기 종속      | `.engine`은 변환한 Jetson과 TensorRT 버전에서만 동작합니다. 기기마다 다시 변환하고 git에는 올리지 않습니다 |
| 모델 변경      | 모델을 새로 학습하면 다시 변환해야 합니다                                                                |
| 분류 모델 지정 | `.engine`은 `YOLO(path, task='classify')`로 불러야 합니다. 지정하지 않으면 detect로 인식되어 `IndexError`가 납니다 |
| 경고           | `'half' is deprecated`와 `engine plan file across different models of devices`는 무시해도 됩니다         |
