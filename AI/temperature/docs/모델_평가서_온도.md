# 온도 예측 및 팬 제어 모델 평가서

작성 기준: 2026-10-22. 평가 대상: LSTM v6와 동일 분할로 재학습한 제약 선형회귀 baseline.

## 1. 평가 목적과 지표 적용 범위

본 모듈은 카메라 객체 탐지가 아니라 센서 시계열을 이용한 미래 온도 회귀 모델이다. 따라서 바운딩박스의 IoU와 검출 순위를 평가하는 mAP는 적용하지 않는다. 온도 예측에는 MAE·RMSE를, 예측값을 26°C 기준으로 이진화한 위험 판정에는 Accuracy·Precision·Recall·F1 및 오탐·미탐 수를 사용한다. 이 Accuracy는 온도를 정확히 맞힌 비율이 아니라 **5초 뒤 상한 이상 여부를 맞힌 비율**이다.

모델 예측, 정책 재생, 실제 장치 제어를 별도로 평가한다. 예측 오차가 작다는 사실만으로 팬 제어의 안전성이나 에너지 절감을 입증하지 않는다.

| 평가 층위 | 평가 질문 | 주요 지표 |
|---|---|---|
| 온도 회귀 | 미래 온도를 얼마나 정확히 추정하는가 | MAE, RMSE, run별 평균, 가열/무가열 분리 |
| 끝점 위험 판정 | 5초 뒤 실제 온도가 26°C 이상인지 맞히는가 | TP/TN/FP/FN, Precision, Recall, F1, Accuracy |
| 선제 대응 | 실제 초과보다 먼저 명령을 상향하는가 | 사건별 성공률, signed 선행시간, 정상 상태 상향 |
| 실제 제어 | 상한 초과를 줄이며 효율적으로 운전하는가 | 최고 온도, 초과시간·적분, 회복시간, 추정 Wh, PWM 변경 |

## 2. 데이터와 평가 설계

4초 가열 9 run, 6초 가열 18 run, 무가열 정상 팬 운전 9 run으로 총 36 run·6,218행을 사용했다. 최신 모델에는 30초 가열 자료와 추가 증강 사본을 사용하지 않았다.

| 분할 | run 수 | 원시 행 | v6 유효 윈도우 |
|---|---:|---:|---:|
| Train | 19 | 2,954 | 2,595 |
| Validation | 8 | 1,589 | 1,456 |
| 개발 Test | 9 | 1,675 | 1,532 |

동일 실험의 중첩 윈도우가 분할 간 섞이지 않도록 run 단위로 나눴다. 정규화 통계는 train으로만 계산했다. 예측 정량 비교는 미래 정답이 존재하고 예측 구간 PWM이 유지된 공통 시점을 사용한다. 회귀 baseline 역시 같은 train run으로 재학습했으며, 1초 변화율 학습에 유효 연속 관측 2,935쌍을 사용했다.

이 test는 개발 중 반복 확인한 **고정 개발 평가셋**이다. run 중복 방지와 별개로 반복 열람에 따른 선택 편향은 남으며, 완전히 독립적인 최종 시험으로 소개하지 않는다.

## 3. 모델 선정과 학습 설정

### 3.1 LSTM 선정 근거

온도에는 현재값뿐 아니라 최근 상승·하강 추세와 열관성이 반영된다. LSTM은 순서가 있는 짧은 이력의 비선형 패턴을 학습할 수 있어 연구 대상으로 선택했다. 초기에는 회귀 baseline·Random Forest·LightGBM·XGBoost·LSTM을 동일 평가 시점으로 비교했다.

| 초기 10초 test, 1,196시점 | MAE °C | RMSE °C | FP | FN |
|---|---:|---:|---:|---:|
| 제약 회귀 baseline | 0.2712 | 0.4645 | 18 | 17 |
| Random Forest | 0.1165 | 0.3251 | 21 | 8 |
| LightGBM | 0.1445 | 0.3424 | 28 | 20 |
| XGBoost | 0.1385 | 0.3783 | 12 | 18 |
| LSTM | 0.1140 | 0.2801 | 2 | 68 |

최초 선정은 test 이전 validation의 오탐률 10% 이하 조건, 미탐, run 평균 MAE 순으로 이루어졌다. 초기 LSTM은 낮은 평균 오차·적은 오탐에 비해 미탐이 많았다. 이 문제를 계기로 다중 변화율, 상승 과소예측 가중, 정상 운전 자료, 다중 시점 예측 및 보조 규칙을 검토했다. 위 초기 실험은 최신 5초·36 run 실험과 데이터·입력·예측 시점이 달라 직접적인 개선율 계산에 사용하지 않는다. 최신 조건의 트리 모델 재대조는 남은 과제다.

### 3.2 최신 v6 설정

| 항목 | 설정 |
|---|---|
| 입력 | 8표본 × 10특성 |
| 주요 특성 | 상대 온도, 평활 변화율, 실제 흡기·배기 PWM, 원본 1·3·5초 변화율, 절대 온도, 후보 PWM |
| 출력 | 1·3·5초 뒤 온도 변화량, 미래 5초 구간의 26°C 이상 위험 점수 |
| 구조 | 1-layer LSTM, hidden 32, 온도 head·위험 head |
| 파라미터 / 파일 | 5,764개 / 29,193 bytes, 약 28.5 KiB |
| Optimizer | AdamW, learning rate 0.001, weight decay 0.001 |
| Batch / epoch | 128 / 최대 100, 선택 후보 실행은 41 epoch에서 종료 |
| 조기 종료 | validation 선택 손실 12회 연속 미개선, 최적 가중치 복원 |
| 손실 | SmoothL1(beta=0.2)+0.1×제곱 오차, 상승 과소예측 추가 가중, 변화율·위험 보조 손실 |
| 균형 | run별 사례 수 역수 기반 가중 |
| 추가 증강 | 미적용 |
| 추론 | 현재 런타임 CPU 경로 |

41은 실행 종료 epoch이며 최적 가중치 epoch로 단정하지 않는다. 학습 장비와 PyTorch·Python 버전은 실제 학습 환경 기록을 추가 첨부해야 한다.

v6는 최근 이력의 선형 추세에 LSTM 보정량을 더하는 구조다. 별도 회귀 baseline의 출력을 보정하는 모델은 아니다. baseline은 열전달 방향성을 참고한 비음수 제약 선형회귀로, 엄밀한 열수지 기반 물리 모델과 구분한다. 같은 분할 재학습에서 흡기·배기 냉각 계수가 모두 0으로 추정되어 팬 효과의 식별에는 실패했다.

### 3.3 증강 미적용의 근거

초기 잡음 증강 대조는 일부 후보에서 개선됐지만 일관적이지 않았고, 당시 선정 기준에서는 원본 학습 후보가 선택됐다. v4~v6에서는 원본 데이터와 run 분할을 고정하고 입력·손실·정책의 변화를 비교했다. 이는 데이터가 충분하다는 뜻이나 최신 v6에서 무증강이 최적이라는 증거는 아니다. 실제 팬 전이·발열 조건의 추가 정보는 단순 잡음 복제로 생기지 않으므로 신규 실험과 train 한정 증강 대조를 병행할 계획이다.

## 4. 평가 정의

회귀 오차는 예측 온도에서 동일 목표 시각의 실제 온도를 뺀 값이다. MAE는 절대 오차 평균, RMSE는 제곱 오차 평균의 제곱근이다. 큰 실패의 영향을 확인하기 위해 두 지표를 함께 보고한다.

- 실제 양성: 5초 뒤 실제 온도 ≥26°C.
- 예측 양성: 5초 뒤 예측 온도 ≥26°C.
- FP: 미래 실제 <26°C이나 예측 ≥26°C.
- FN: 미래 실제 ≥26°C이나 예측 <26°C.
- Precision = TP/(TP+FP), Recall = TP/(TP+FN).
- F1 = 2TP/(2TP+FP+FN), Accuracy = (TP+TN)/전체 시점 수.

여기서 FP/FN은 시점 수다. 연속된 여러 미탐이 하나의 가열 사건에서 발생할 수 있다. 또한 현재 온도가 이미 26°C 이상이어도 미래 끝점 예측이 26°C 미만이면 회귀 평가상 FN일 수 있다. 이것이 곧 실제 제어기의 무대응을 뜻하지는 않는다. 실제 온도·상승률·비상 규칙은 별도로 작동한다.

## 5. 동일 데이터 최종 성능

### 5.1 5초 뒤 끝점 온도 및 위험 판정

같은 9 run·1,532시점을 평가했다. 실제 양성 532시점, 실제 음성 1,000시점이다. 아래 값은 보조 규칙이나 안전 여유를 더하지 않은 온도 회귀 출력의 평가다.

| 모델 | MAE °C | RMSE °C | Accuracy | Precision | Recall | F1 | FP | FN |
|---|---:|---:|---:|---:|---:|---:|---:|---:|
| 재학습 회귀 baseline | 0.1535 | 0.3317 | 97.91% | 0.9808 | 0.9586 | 0.9696 | 10 | 22 |
| LSTM v6 | 0.1758 | 0.3323 | 98.50% | 0.9885 | 0.9680 | 0.9782 | 6 | 17 |

| 실제 / 예측 | 회귀: 정상 | 회귀: 이상 | v6: 정상 | v6: 이상 |
|---|---:|---:|---:|---:|
| 실제 정상 | TN 990 | FP 10 | TN 994 | FP 6 |
| 실제 이상 | FN 22 | TP 510 | FN 17 | TP 515 |

v6는 FP가 10→6, FN이 22→17로 감소했다. 그러나 전체 MAE·RMSE는 회귀보다 나빴다. 정확도 하나만으로 전반적인 우위를 주장하지 않는다.

### 5.2 가열·무가열과 실험별 평가

| 구간 | 표본 수 | 회귀 MAE °C | v6 MAE °C | 회귀 RMSE °C | v6 RMSE °C |
|---|---:|---:|---:|---:|---:|
| 가열 run | 668 | 0.1756 | 0.1020 | 0.4742 | 0.3311 |
| 무가열 run | 864 | 0.1365 | 0.2328 | 0.1460 | 0.3332 |
| run별 지표의 동일 비중 평균 | 9 run | 0.2104 | 0.1796 | 0.3996 | 0.3268 |

가열 run에서 MAE는 약 41.9% 낮았지만 무가열 오차는 증가했다. 긴 정상 run의 영향을 줄인 run별 평균에서는 v6가 낮았다. 9 run 쌍체 bootstrap의 MAE 차이 구간은 0을 포함하므로 통계적인 전체 우위를 확정하지 않는다.

### 5.3 다중 예측 시점

| v6 예측 시점 | MAE °C | RMSE °C |
|---|---:|---:|
| 1초 | 0.0244 | 0.0584 |
| 3초 | 0.1019 | 0.1962 |
| 5초 | 0.1758 | 0.3323 |

3~5초 예상 변화율 MAE는 0.0444°C/s다. 별도 위험 head의 ‘미래 5초 안 한 번이라도 이상’ 판정은 FP 14/FN 14이며 끝점 경보 FP 6/FN 17과 라벨 정의가 다르므로 혼합하지 않는다.

## 6. 오탐·미탐 사례와 원인 분석

시점 식별자는 원본 예측 CSV의 Unix timestamp이며 예측을 생성한 입력 시각이다. 정답은 별도 target_timestamp에 대응한다. 아래는 실패 원인을 설명하기 위한 사례이며 전체 실패를 대표하는 무작위 표본은 아니다.

### 6.1 v6 오탐 사례

| run | 입력 timestamp | 현재 원본 °C | 실제 5초 뒤 °C | v6 예측 °C | 해석 |
|---|---:|---:|---:|---:|---|
| 01_intake_weak_exhaust_weak copy 2 | 1792307808.076 | 24.61 | 25.42 | 26.836 | 상승량 과대예측. 실제 끝점은 정상이나 상한 초과로 예측 |
| 09_intake_strong_exhaust_strong copy 2 | 1792309118.069 | 26.10 | 25.96 | 26.012 | 냉각 중 경계 통과를 늦게 예측한 근접 오탐 |
| 09_intake_strong_exhaust_strong copy 2 | 1792309117.070 | 26.13 | 25.99 | 26.042 | 같은 냉각 사건의 인접 시점. 별개 사건으로 세지 않음 |

첫 사례의 오차는 약 +1.416°C이며 단순 경계 잡음만으로 설명하기 어렵다. 나머지 두 사례는 26°C 부근의 작은 오차가 분류 결과를 바꾼 경우다. 상승 추세 잔차 보정과 센서·전처리 영향은 원인 후보이며, 단일 행만으로 원인을 확정하지 않는다.

### 6.2 v6 미탐 사례

| run | 입력 timestamp | 현재 원본 °C | 실제 5초 뒤 °C | v6 예측 °C | 해석 |
|---|---:|---:|---:|---:|---|
| 05_intake_medium_exhaust_medium copy 2 | 1792308446.068 | 25.15 | 28.04 | 25.218 | 현재 정상이나 5초 뒤 급상승을 충분히 반영하지 못함 |
| 01_intake_weak_exhaust_weak copy | 1792398663.061 | 25.70 | 28.16 | 25.568 | 급상승 전환을 놓쳐 약 −2.592°C 과소예측 |
| 01_intake_weak_exhaust_weak copy | 1792398662.053 | 25.71 | 28.02 | 25.585 | 같은 사건의 인접 미탐. 시점 수와 사건 수 구분 필요 |

미탐은 짧은 입력 이력에 아직 발열 징후가 충분하지 않은 급상승 초반에서 발생할 수 있다. 공기 센서의 응답 지연과 인과적 중앙값 평활화, 부족한 발열·팬 전이 다양성은 추가 점검 대상이다. Heat_Load는 평가 메타데이터일 뿐 입력이 아니므로 기록된 가열 시작을 모델이 직접 아는 것은 아니다.

## 7. 실제 연결 검증과 최종 판단

Jetson·ESP32·팬 연결 시험의 v6 두 가열 사건에서 실제 26°C 도달 약 1초 전에 팬 상향을 관측했다. 최초 상향은 모두 원본 상승률 보조의 기여였다. 첫 사건은 25.92°C에서 60/100, 다음 표본 26.91°C에서 100/100이었다. 두 번째는 25.67°C에서 60/100, 다음 표본 26.35°C에서 100/100이었다. 두 사건 모두 상한 초과를 막지는 못했다.

따라서 v6는 **가열 구간 예측과 조기 대응을 개선하기 위한 통합 연구 후보**다. 전반적 예측 최우수 모델이나 26°C 안전 유지에 성공한 최종 제어기로 결론 내리지 않는다. 회귀 baseline과 예측 오차가 작은 v4/v5를 대조군으로 유지한다.
