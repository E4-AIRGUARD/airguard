# LSTM v4: 다중 변화율과 상승 구간 학습

## 해결하려던 문제

이전 LSTM은 무가열 상태에서도 과대 예측하고, 급상승 시작에서는 실제 온도를 뒤따르는 문제가 있었다. 현재 온도 하나보다 최근 상승 흐름을 반영하도록 원본 1/3/5초 변화율을 추가했다. Physics를 비교 기준으로 유지했다.

## 설계와 데이터

- 최근 8개 샘플로 5초 뒤 온도 변화를 예측한다.
- 상대 온도, 평활 변화율, 실제 PWM, 원본 다중 변화율과 후보 PWM을 입력한다.
- 4초/6초 가열 및 무가열 팬 정상운전 36 run을 train 19 / validation 8 / test 9로 분리한다. 30초 가열은 제외한다.
- run별 손실 기여를 균형화하고 상승 구간의 과소예측에 가중치를 준다.
- v4 학습 함수에는 노이즈 사본 생성 등 데이터 증강이 없다. 평활화·윈도우 생성·가중 학습은 증강이 아니다.

코드: `src/train_multirate_rise_lstm.py`, `src/multirate_temperature_lstm.py`.
모델: `models/lstm_temperature_multirate_v4.pt`.
위 파일들은 이전 학습/모델 커밋에 포함되어 있으며 이번에 중복 추가하지 않는다.

## 확인한 한계와 다음 단계

공통 개발 test 1,532개 예측에서 MAE 0.0685°C, RMSE 0.2559°C, 오탐 1 / 미탐 18건이었다. 하지만 원래 정책의 실제 루프 재생에서는 PWM 변경 66회, 무가열 변경 46회가 발생했다. 온도 예측 오차가 작아도 제어 안정성이 자동 확보되지는 않았다.

이를 해결하기 위해 다음 v5에서는 모델 복잡도를 늘리기보다 정책 전환 히스테리시스, 현재 조합 유지, 안전 위험과 경제적 변경 대기 분리에 집중했다. 재생 명령은 기록된 온도를 바꾸지 않으며 실제 냉각·에너지 절감을 증명하지 않는다. 이 test는 반복 확인한 개발 평가이며 독립 최종 검증이 아니다.
