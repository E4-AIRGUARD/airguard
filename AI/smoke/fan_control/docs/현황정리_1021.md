# 팬 자동제어 모델 현황 정리 (10/21, 추가 측정 전, 갱신판)

## 한 줄 요약
PM이 오르면 가장 빠른 조합으로 올리고, 내려오는 구간에서는 마감(PM50 도달 기준) 안에서 에너지가 적은 조합을 고르는 제어기가 젯슨 실기에서 동작함을 확인했습니다. PWM은 세분화하지 않고 약/중/강(35/60/100) 9개 조합으로 갑니다. 다만 "시간 예측"이 환경마다 10~30% 빗나가고, 조합당 반복 측정이 적어서 어떤 조합이 최선인지는 아직 확정하지 못했습니다.

## 1. 통계 시간표 vs 회귀

| 기준 | 통계 시간표 | 회귀 |
| --- | --- | --- |
| 예측 오차 (10/18 holdout 9회) | 5.1초 | 4.8초 (차이 없음) |
| 예측 오차 (10/20 젯슨 환경 9회) | 16.6초 | 13.2초 (둘 다 나쁨, 평균만 쓰는 것과 비슷) |
| 안 해 본 조합 / 새 PWM(45%, 80% 등) | 예측 불가 | 가능 (조합 하나 빼고 예측 오차 5.8초) |
| 데이터가 적을 때 | 조합별 평균이라 반복 편차가 그대로 반영됨 | 파라미터 5개라 평활화되지만 100 계열이 거의 같은 값이 되어 구분 못 함 |
| 설명하기 | 쉬움 (표를 보간) | 쉬움 (흡기, 배기가 각각 포화하는 효과와 상호작용) |
| 갱신 | 데이터를 넣으면 평균만 바뀜 | 데이터를 넣고 다시 맞추면 됨 |

- 결론: 정확도는 같고 데이터가 이미 환경별로 달라서 둘 다 한계가 있습니다. 프로젝트 목적(실시간으로 팬 세기를 고르고, 앞으로 PWM을 세분화할 수 있음)에는 **회귀가 더 맞습니다.** 시간표는 비교와 백업용으로 남깁니다(`--model`로 번갈아 실행 가능).

## 3. 현재 모델의 문제

1. **환경 변동이 큼:** 같은 조합이 회차마다 10~20초씩 다르고(100/60: 옛 49~51초, 10/20 69초), 10/20 환경은 옛 데이터보다 약 25~30% 빠릅니다. 모델이 조합 이외의 요인(연기 양, 시작 농도, 혼합)을 못 봅니다.
2. **조합당 반복이 적음:** 2~3회(10/20은 1회)라서 조합 사이 순위를 믿을 수 없습니다.
3. **전력은 여전히 추정값:** 실측 RPM으로 바꿨지만 전력계로 잰 값이 아니라서 절대 W는 틀릴 수 있고, 같은 PWM에서도 세션에 따라 RPM이 약 10% 달라집니다.
4. **500 초과 구간:** 원본 PM이 500을 넘는 동안은 농도를 모른다고 보고 늘 가장 빠른 조합을 씁니다. 10/20 센서는 1000 이상도 읽어서 이 구간에 에너지를 더 쓸 수 있습니다.
5. **검증 근거 부족:** 자동제어 vs 고정 100/100, 35/35 비교가 없어서 에너지 절감을 말할 수 없습니다.
6. **단순 실시간 보정은 효과가 없었음:** 500→300 구간 속도로 나머지를 보정하는 방법은 9회에서 오차가 오히려 늘었습니다.
7. **이미 고친 것:** 급상승 반응, 500 초과 값 처리, 센서 한 번 누락 무시, 마감 시작 기준, 범위 기준(`--range-pm`), **마감을 PM50 도달 기준으로 변경(기본 70초)**, **전력표를 실측 RPM으로 교체**, **10/20 젯슨 9회를 포함해 회귀 재학습**, 후보를 3개로 고정하지 않고 9개 조합을 1초마다 비교.

## 4. 필요한 데이터 (추가 측정: 필수 9회 + 선택 8회)

PWM 세분화는 하지 않고 약/중/강 조합을 유지합니다(하루이틀 안에 마무리). 전력표를 실측 RPM으로 바꾸면서 모델이 고를 만한 조합이 100/35, 35/60, 35/100, 60/35(그리고 35/35)로 바뀌어, 선택 측정 대상도 100/60 대신 이 조합들로 바꿨습니다.

| 데이터 | 구분 | 이유 | 쓰는 방법 |
| --- | --- | --- | --- |
| 자동제어, 고정 100/100, 고정 35/35 각 3회 (9회) | 필수 | 자동제어의 성능 근거 | 같은 연기 조건에서 PM50 도달 시간, 마감 달성, 에너지, 조합 전환 횟수 비교. 100/100과 35/35 반복 데이터는 모델에도 추가 |
| 35/60, 60/35, 100/35, 35/100을 2회씩 더 (8회) | 선택 | 조합당 3회가 되어야 순위와 평균이 안정됨 | 제어기가 쓸 조합 확인, 조합당 3회로 재학습 |
| 연기 투입량, 시작 PM, 최고 PM 기록 | 같이 기록 | 같은 조합의 회차 변동 원인을 찾기 위함 | 모델의 입력 변수 후보로 검증 |
| 전력계 실측 (가능하면) | 선택 | 에너지가 추정값이라 절대 W를 모름 | 전력표 교체 |

시간이 부족하면 필수 9회만 해도 제출은 가능합니다. 이 9회가 없으면 "자동제어가 고정보다 낫다"는 주장은 할 수 없습니다.
