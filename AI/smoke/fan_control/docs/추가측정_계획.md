# 추가 측정 계획 (필수 9회 + 선택 8회)

같은 프로토콜(PM40에서 시작하고 PM40에서 종료, 연기 투입 Space 1회, 제거 Space 1회)로 A01~A09와 같은 환경에서 진행합니다. 순서는 블록 안에서만 무작위로 섞었습니다.

## 목적
- 블록 1~3 (필수 9회): 자동제어가 고정 100/100, 고정 35/35보다 시간과 에너지에서 어디에 놓이는지 비교.
- 블록 4~5 (선택 8회, 시간이 남을 때): 모델이 고를 만한 4개 조합(35/60, 60/35, 100/35, 35/100)을 2회씩 더 측정.

## 실행 방법

**먼저 (한 번만):** 이미 센서/팬 연결(`read_pm`, `set_fan`, `--port`)을 채워 둔 젯슨의 `run_on_jetson.py`를 그대로 쓰세요. 새 zip의 `run_on_jetson.py`는 그 부분이 비어 있어서 그대로 덮어쓰면 안 됩니다. 새 zip에서 아래 3개만 젯슨 실행 폴더로 교체합니다.
- `fan_controller.py`, `model.json`, `fan_power_rpm추정.csv`
- 기존 `run_on_jetson.py`에는 `--deadline` 기본값이 70초(PM50 기준)로 바뀐 것이 새 zip에 있으므로, 아래 명령처럼 `--deadline 70`을 직접 적어 주면 안전합니다.

- 기존 `run_on_jetson.py`가 예전 버전이면 제어기를 이렇게 만드는 두 줄이 있을 것입니다. 새 zip과 같은 동작(9개 조합 비교, 1초 재계획)이 되도록 아래처럼 바꿔 주세요.
```
planner = Planner(model, prune=False)
ctl = FanController(planner, a.deadline or None, interval_s=1.0, range_pm=50.0)
```
  (새 zip의 `run_on_jetson.py`에는 이미 들어 있으니 그 파일의 해당 두 줄을 참고하세요.)

**자동제어 회차** (`<순서>`는 순서표의 순서 번호, 예: 순서 1이면 `01`):
```
python3 run_on_jetson.py --live --port /dev/ttyUSB0 --deadline 70 --log log_자동_<순서>.csv
```
종료 후 로그 파일을 그대로 보관합니다(덮어쓰지 않게 순서 번호를 파일명에 넣었습니다).

**고정 조합 회차:** A01~A09를 돌린 측정 방식과 같게 해당 PWM으로 고정하고, 원자료(`records.jsonl` 폴더)를 그대로 저장합니다. 파일명 또는 폴더명에 순서 번호를 포함해 주세요.

시작 조건은 전부 같게: 환기 후 PM40 이하로 3초 유지, 팬 정지 확인, 연기 투입 후 제거(목표 2초) 뒤 30초 대기.

## 같이 적어 둘 것
연기 투입 방법과 양(모기향 개수, 투입 시간), 시작 PM, 최고 PM, 환기 후 대기 시간, 이상 상황. `추가측정_순서표.csv`의 빈 칸에 적으면 됩니다.
