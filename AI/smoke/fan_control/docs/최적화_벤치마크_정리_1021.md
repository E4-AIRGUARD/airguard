# 팬 자동제어 최적화 벤치마크 정리 (2026-10-21)

전은 10/21 오전 제어기(92행 회귀 모델, 팬 켠 시점 기준 마감 70초), 후는 최종 제어기(161행 회귀 모델, PM이 500 아래로 내려온 시점 기준 마감 70초, 속도 보정, 정체 감지, 최소 유지 25초)예요. 환경은 Jetson Orin Nano, PMS5003, ESP32 PWM, 모기향 약 2초 투입이고, 굵은 글씨는 더 좋은 쪽입니다. 에너지는 RPM 기반 추정값이며 전력계 실측이 아니고, 측정 횟수가 적어(전 2회, 후 3회) 경향으로만 봐야 합니다.

## 1. 개선 전후

| 구분 | 항목 | 전 | 후 | 변화 |
|---|---|---|---|---|
| 결과 | PM50까지 평균 시간 | 168초 | **90초** | 약 46% 감소 |
| 결과 | 평균 추정 에너지 | 206 J | **103 J** | 약 50% 감소 |
| 동작 | 불가능 판정으로 최고속 강제한 횟수(최대) | 197회 | **27회** | 대폭 감소 |
| 동작 | 조합 전환 횟수 | 5.5회 | **4.3회** | 소폭 감소 |
| 예측 | PM50까지 남은 시간 오차 | 8.4~10.2초 | **6.4~7.9초** | 1.5~3초 감소 |
| 예측 | PM100까지 남은 시간 오차 | 2.2~2.5초 | **1.1~1.8초** | 0.4~1.4초 감소 |

**요약**: 시간과 에너지는 모두 절반 가까이 줄었지만 전은 유효 2회뿐이고 연기 양도 달라서 엄밀한 비교는 아닙니다. 가장 효과가 큰 것은 마감 시계를 500 아래부터 센 것이고, 전환 횟수는 거의 안 달라졌습니다.

## 2. 사용한 데이터

| 시기 | 데이터 | 양 | 쓴 곳 |
|---|---|---|---|
| 10/08, 10/15 | 챔버 실험 (조합 9개) | 20회 | 첫 시간표 학습 |
| 10/18 | 재실험 (조합당 2회) | 18회 | 독립 평가 후 학습 추가 |
| 10/20 | 젯슨 A01~A09 | 9회 | 평가, RPM 추출, 학습 추가 |
| 10/21 | 젯슨 A01~A09 | 9회 | 학습 추가 |
| 10/21 | new_problem 필수 (자동제어, 100/100, 35/35 각 3회) | 9회 | 고정 6회 학습 추가 |
| 10/21 | new_problem 선택 (4조합 각 2회) | 8회 | 학습 추가 |
| 10/21 | PM500에서 팬 시작, 9조합 | 9회 | 학습 추가 |
| 10/21 | 161행 모델 중간 시험 | 9회 (유효 7회) | 평가용 |
| 10/21 | 최종 측정 `Re_nEw` | 9회 | 평가용 |

| 구분 | 회수 | 용도 |
|---|---|---|
| 학습 (train) | 79회 (가중치 반영 161행) | 최종 모델 학습 |
| 검증 (val) | 36회 (10/18, 10/20, 10/21 각각 학습 전에 평가) | 모델 비교, 속도 보정 확인 |
| 시험 (test) | 9회 (`Re_nEw`) | 최종 성능 보고 |

**요약**: 무작위 분할이 아니라 측정 순서대로 새 데이터를 학습 전에 평가했습니다. 최종 모델 기준 독립 시험은 `Re_nEw` 9회뿐입니다.

## 3. 통계 시간표 vs 회귀

| 항목 | 통계 시간표 | 회귀 |
|---|---|---|
| 10/18 holdout 오차 | 5.1초 | **4.8초** |
| 10/20 젯슨 환경 오차 | 16.6초 | **13.2초** |
| 안 해 본 조합 예측 | 불가 | **가능 (오차 5.8초)** |
| 파라미터 | 조합별 평균 | **5개** |

**요약**: 10/18에서는 사실상 같고 젯슨에서는 회귀가 약간 낫습니다. 새 PWM을 쓸 수 있어 회귀를 기본으로 했고 시간표는 백업입니다.

## 4. 회귀 모델 개선 내역

| 단계 | 문제 | 조치 | 결과 |
|---|---|---|---|
| 1 | 더하기만 한 식은 35/35를 76초로 낮게 예측 (실측 약 90초) | 흡기 x 배기 상호작용 항 | 35/35 예측이 실측에 근접 |
| 2 | h를 0.02까지 허용하자 계수 폭주 | h를 0.1 이상으로 제한 | 계수 안정 (h = 0.10) |
| 3 | 학습 38행 | 10/20 젯슨 9회 추가 → 65행 | 젯슨 환경 반영 |
| 4 | 10/21 환경 차이 | 10/21 9회 추가 → 92행 | 환경 차이 평균화 |
| 5 | PM 1,000 이상에서 팬 켠 측정이 많음 | 500 아래 구간만 뽑아 추가 → 161행 | 고정 조합 예측 수렴 (92행 대비 1~6초 차이) |

**요약**: 계수는 92행과 161행에서 거의 같아서 조합별 평균 예측은 수렴한 것으로 봅니다.

## 5. 최종 측정(Re_nEw) 결과

최종 측정은 자동제어, 고정 100/100, 고정 35/35 각 3회를 섞어 돌린 9회 비교입니다. PM500 이상(연속 표본)에서 팬을 켜고 PM40 이하 3초 유지 시 종료했고, 시간은 PM이 500 아래로 내려온 시점부터 잽니다.

| 방식 | PM100까지 (초) | PM50까지 (초) | PM50 평균 | 에너지 (J) | 에너지 평균 | 마감 70초 달성 |
|---|---|---|---|---|---|---|
| 자동제어 | 30, 34, 45 | 50, 63, 157 | 90초 | 72, 80, 156 | 103 J | 2/3 |
| 고정 100/100 | 33, 31, 33 | 52, 49, 72 | **58초** | 178, 174, 211 | 188 J | 2/3 |
| 고정 35/35 | 62, 61, 57 | 92, 89, 81 | 87초 | 25, 25, 19 | **23 J** | 0/3 |

**요약**: 자동제어 1, 2번은 100/100과 같은 속도에 에너지가 55~60% 적었고, 3번은 PM 54~65 근처 정체로 157초가 걸렸습니다. 에너지는 35/35가 가장 적어서 자동제어가 에너지 최소는 아닙니다.

## 6. 시간 예측 모델 수준

| 항목 | 수준 |
|---|---|
| 500에서 PM100까지 | 평균 오차 약 2초 |
| 500에서 PM50까지 | 평균 오차 8~10초, 중앙값 2~3초 |
| 큰 경향 (강/강 빠름, 약/약 느림) | 맞춤 |
| 비슷한 조합끼리 순위 | 차이가 오차보다 작아 신뢰 불가 |
| 500 위 구간 | 모델 밖, 최고속 |

**요약**: PM100까지는 쓸 만하고 PM50 근처는 바닥값(약 45~50) 때문에 흔들립니다. 데이터를 늘려도 평균 예측은 거의 안 바뀌어서 오차는 데이터 양이 아니라 마지막 구간 변동에서 나옵니다.

## 7. TensorRT 같은 추론 최적화는 필요한가

| 항목 | 내용 |
|---|---|
| 모델 크기 | 회귀 계수 5개, 계산이 사실상 0초 |
| 병목 | 추론이 아니라 센서 주기와 팬이 공기를 바꾸는 시간 |
| 필요 여부 | **불필요** (이미지 모델과 달리 속도 최적화 대상이 아님) |

**요약**: 벤치마크 대상은 추론 속도가 아니라 "같은 속도에서 에너지를 얼마나 아꼈는가"입니다.

## 8. 한계

| 항목 | 내용 |
|---|---|
| 표본 수 | 조건당 3회, 차이가 우연일 수 있음 |
| 정체 문제 | 5% 기준 경계에서 최고속과 35/35를 오가는 문제가 남음 (히스테리시스로 해결 가능, 미적용) |
| 에너지 값 | RPM 기반 추정, 팀원 식과 가정이 달라도 순위는 같음 |
| 마감 70초 | 10/18 가상 시험(140초 - 꼬리 70초) 기반, 요구 사양 아님 |
| 개선 전후 | 전이 유효 2회, 연기 양이 달라 엄밀한 비교 아님 |

**요약**: 자동제어가 확실히 낫다고는 말할 수 없고, "정상 동작한 회차에서 100/100 속도에 에너지를 절반쯤 쓴다"까지가 근거 있는 결론입니다.
