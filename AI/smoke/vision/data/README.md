# data

이 폴더에는 데이터를 올리지 않습니다(`.gitignore`로 제외). 학습 데이터셋 `ds_cls`(약 400MB zip)는 별도 저장소(예: Google Drive, GitHub Release)에 올리고 링크를 여기에 적습니다.

## 구성 (v4)
```
ds_cls/
├─ train/ {smoke, no_smoke}   # 2,590장 (연기 905 / 없음 1,685)
├─ val/   {smoke, no_smoke}   #   894장 (연기 320 / 없음 574)
└─ test/  {smoke, no_smoke}   #   311장 (연기 123 / 없음 188), 학습·기준 선택에 쓰지 않음
```
- 이미지 크기: 640x360 (resize) 후 `흑백 → CLAHE(clipLimit 6.0, 8x8) → INFERNO 컬러맵`을 적용한 사진입니다. 일반 웹캠 영상에 적용하는 "열화상 느낌의 가상 필터"이고 열화상 카메라가 아닙니다.
- 연기 발생원은 모기향입니다.
