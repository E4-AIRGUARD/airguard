# 최종 모델 v4 성능 지표 (이전 모델 v3와 비교)

두 모델은 같은 구조(yolo11n-cls, 파라미터 약 153만 개, 파일 약 3.2MB)이고, v4는 v3 데이터에 모기향 합성 4종(모기향만 붙인 빈 화면, 지우기 얼룩 대조군, 모기향 지운 연기, 모기향 위치 옮긴 연기)을 더해 다시 학습했습니다. 굵은 글씨는 더 좋은 쪽입니다. 기준값은 val에서 F1이 가장 높은 값(v3 0.50, v4 0.40)입니다.

## 1. 실험실 test (연기 123장 / 연기 없음 188장, 학습에 사용하지 않음)
| 기준 | 모델 | 연기 잡음 | 오탐 | 재현율 | 오탐률 | 정밀도 | F1 |
|---|---|---|---|---|---|---|---|
| val 선택 기준 | v3 (0.50) | 112 | 22 | 91.1% | 11.7% | 83.6% | 0.872 |
| val 선택 기준 | **v4 (0.40)** | **114** | **16** | **92.7%** | **8.5%** | **87.7%** | **0.901** |
| 0.40 | v3 | **117** | 26 | **95.1%** | 13.8% | 81.8% | 0.880 |
| 0.40 | **v4** | 114 | **16** | 92.7% | **8.5%** | **87.7%** | **0.901** |
| 0.50 | v3 | **112** | 22 | **91.1%** | 11.7% | 83.6% | 0.872 |
| 0.50 | **v4** | 108 | **12** | 87.8% | **6.4%** | **90.0%** | **0.889** |

| 기준 무관 지표 | v3 | v4 |
|---|---|---|
| AUROC | 0.961 | **0.977** |

**요약**: val 선택 기준에서 v4는 재현율(92.7% vs 91.1%), 오탐률(8.5% vs 11.7%), 정밀도(87.7% vs 83.6%), F1(0.901 vs 0.872)이 모두 v3보다 좋았습니다. 같은 기준 0.40에서는 v3가 연기를 3장 더 잡지만(재현율 +2.4%p) 오탐이 10장 많았습니다. 기준과 무관한 AUROC도 v4가 높았습니다. (v3, v4 모두 이 test를 같은 방식으로 다시 채점해서 확인했습니다.)

**요약**: 모기향 합성 시험에서 v4가 크게 좋아졌습니다. 다만 원본에 모기향을 붙여넣은 시험은 v4도 40장 중 39장을 연기라고 판단해서 모기향 의존이 완전히 풀리지는 않았습니다.

## 3. 실사용 영상 cmp2 (Jetson 웹캠, 261.8초, 연기 약 17초)
데모와 같은 판정 규칙(EMA 0.3, 유지 2초)으로 쟀습니다.
| 모델 | 켜기 기준 | 오탐 시간 (연기 없는 216초 중) | 연기 A 첫 켜짐 | 연기 B 첫 켜짐 | 켜진 비율 A / B |
|---|---|---|---|---|---|
| v3 | 0.40 | 7.8초 | **0.6초** | **0.7초** | **92% / 95%** |
| **v4** | 0.40 (현재) | **0.0초** | 2.1초 | **0.7초** | 71% / 58% |
| v3 | 0.50 | **0.0초** | **0.9초** | **1.0초** | **88% / 93%** |
| v4 | 0.50 | **0.0초** | 2.4초 | **1.0초** | 67% / 49% |
| v4 | 0.30 | 2.1초 | **0.6초** | **0.7초** | **92%** / 86% |

**요약**: 같은 기준 0.40에서 v4는 오탐이 0초로 줄었지만 연기 A를 2.1초 늦게 잡고 연기 구간의 30~40%를 놓쳤습니다. 기준을 0.30으로 낮추면 v4도 반응(0.6 / 0.7초)과 켜진 비율(92% / 86%)이 v3 수준으로 돌아오고 오탐은 2.1초가 남았습니다.
