# v4 최적화 작업 정리

작성: 2026-10-21. 대상 모델은 `smoke_cls_v4.pt`(yolo11n-cls, 연기 있음/없음)이고 최종 모델이에요. 아래는 이번에 실제로 한 작업과 결과이고, 측정하지 않은 것은 "미측정"으로 표시했어요.

> 최적화 전후의 기준은 최종 모델 v4 하나예요.

## 1. 한 일 요약
| 번호 | 작업 | 종류 | 결과 한 줄 |
|---|---|---|---|
| 1 | 속도·전력 측정 (`.pt`, 2회) | 속도 | 추론 36.1 / 35.1ms, 초당 25.2 / 25.9장, 전력 6.49W |

## 2. 작업별 내용과 결과
### 2-1. 속도 최적화 (TensorRT FP16)
- 방법: `yolo export model=smoke_cls_v4.pt format=engine half=True imgsz=640`으로 Jetson에서 변환하고(266.5초), 같은 스크립트(`bench_speed.py`)로 `.pt`와 `.engine`을 600장씩 2회 측정했어요.
- 결과: 전체 시간 39.66 / 38.62ms → 31.85 / 30.82ms(약 20% 단축), 초당 25.2 / 25.9 → 31.4 / 32.5장, GPU 메모리 62.7 → 9.4MB.
- 전력(tegrastats, 보드 전체): `.pt` 6.49W → TensorRT 5.66W(-13%), 프레임 1장당 에너지 약 251mJ → 174mJ(-30%).
- 정확도 영향: cmp2 영상 1309개 점수의 차이가 평균 0.0002, 최대 0.003이고, 0.4 / 0.5 기준에서 판정이 바뀐 프레임이 0개였어요.
- 해석: 데모는 3프레임마다 한 번 판정하고 카메라가 약 10fps라서 `.pt`도 속도는 충분했어요. 실사용상 큰 차이는 없고 손해도 없는 정도의 개선이에요. 다만 `.engine`은 Jetson과 TensorRT 버전에 묶여 있어서 다른 기기로 옮겨 쓸 수 없고, 모델을 바꿀 때마다 다시 변환해야 해요.

### 2-2. 경보 규칙 검토
- 방법: 데모와 같은 판정기(EMA, 켜기/끄기 기준, 유지 시간)를 0.3초 간격으로 cmp2에 돌려 켜기 기준, EMA, 유지 시간을 비교했어요. 연기 구간(A 159~166초, B 174.5~187.5초)은 직접 정했고 애매한 두 구간(166~174.5초, 187.5~205초)은 채점에서 뺐어요.
- 결과: 켜기 기준 0.40 이상은 이 영상에서 오탐이 0이지만 연기 A 첫 반응이 2초 이상 늦고 연기 구간의 30~40%를 놓쳐요. 0.35 이하는 약 2초 오탐이 나요. 유지 시간 3초가 0.40에서 B 구간 놓침을 줄여요(켜진 비율 58% → 72%).
- 해석: 오탐을 줄일지 연기를 더 잡을지의 선택이에요. 시연에서 오탐이 더 치명적이면 0.40, 놓치면 안 되면 0.30~0.35를 고르세요.
- 한계: 영상 하나로 본 값이에요. 오탐이 순간 1번뿐이라 표본이 매우 적어서, 다른 영상에서 다시 확인해야 해요.

### 2-3. 실험실 test 재측정
- 방법: 학습에 안 쓴 test(연기 123장, 연기 없음 188장)를 같은 `.pt`로 다시 채점했어요.
- 결과: 기준 0.40에서 연기 114장 잡음, 오탐 16장, 재현율 92.7%, 정밀도 87.7%, F1 0.901, AUROC 0.977이에요.
- 해석: 기준 0.30~0.40에서 F1이 0.90~0.91로 거의 같아서, 기준은 위 경보 규칙 결과를 보고 정하면 돼요.

## 3. 결론과 권장
| 항목 | 권장 | 근거 |
|---|---|---|
| 추론 방식 | TensorRT FP16 (선택) | 점수 같고 약 20% 빠르고 전력 13% 낮음. 필수는 아님 |
| 켜기 기준 | 0.40 (오탐 우선) 또는 0.30~0.35 (감지 우선) | cmp2에서 0.40은 오탐 0초, 놓침 30~40% |
| 유지 시간 | 3초 검토 | 0.40에서 B 구간 놓침 감소 |

## 4. 아직 모르는 것 (미측정)
- 다른 영상과 다른 환경에서도 같은 기준이 맞는지.
- 옅은 연기에서의 반응. 시연에서 한 번 확인이 필요해요.
- 불씨만 있고 연기가 없는 장면에서의 반응, 불씨 가림 시험(v4로는 안 했어요).
- 480/320 해상도의 속도와 정확도.
- 학습 시드를 바꿨을 때의 흔들림.
- 데이터를 더 모아 다시 학습하는 개선은 하지 않기로 했어요.
