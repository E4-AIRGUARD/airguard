# 데이터 전처리 방식

프로젝트: E4 AIRGUARD

## 1. 전처리 대상과 순서

팬 제어·온도 가열 실험의 CSV와 연기 농도 실험의 CSV·JSONL을 전처리하였다. 실험 종류와 흡기·배기 PWM 조건별로 데이터를 구분하고, 원본 시각을 기준으로 측정 순서와 시간 간격을 유지하였다.

```text
원본 데이터 읽기 → 시각·중복 검사 → 결측·범위 오류 처리
→ 연속 구간 분리 → 중앙값 필터 → 분석 기준별 시간축 정렬 → CSV 저장
```

## 2. 시각과 중복 처리

| 항목 | 적용 방식 |
| --- | --- |
| 경과 시간 | 원본 실험의 첫 유효 측정 시각을 기준으로 `Time[s]` 계산 |
| 측정 날짜 | 전처리 실행일이 아닌 원본 측정 날짜 사용 |
| 실제 시간 간격 | 행 번호로 시간을 생성하지 않고 측정 공백 유지 |
| 중복 파일 | 기본 CSV 처리에서 SHA256 해시가 동일한 파일은 한 번만 처리 |
| 중복 행 | 시각을 포함한 모든 칼럼 값이 같은 행은 한 번만 사용 |
| 동일 센서값 | 측정 시각이 다르면 별도 관측으로 유지 |
| 시각 오류 | 해석할 수 없는 시각의 행 제외 |
| 시간 역행·동일 시각의 다른 관측 | 별도 연속 구간으로 분리하여 보존 |

## 3. 결측치와 이상값 처리

빈 값, 숫자 변환 실패, NaN·무한대를 무효값으로 처리하였다. 숫자로 변환되는 값에는 다음 범위 기준을 적용하였다.

| 항목 | 허용 범위 |
| --- | --- |
| 온도 | −20~80°C |
| 상대습도 | 0~100%RH |
| 흡기·배기 PWM | 0~100% |
| PM2.5 | 0 이상 |
| 흡기·배기 RPM | 0 이상 |
| 가열 상태 | 0 또는 1 |

범위의 양 끝값은 포함하며, 실제 측정된 0은 유지하였다. `bme_err`·`pms_stale` 상태값이 있는 CSV에서는 해당 값이 0으로 확인되지 않으면 각각 온습도·PM 값을 무효로 처리하였다.

| 데이터 | 결측·범위 오류 처리 |
| --- | --- |
| 팬 제어 실험 | 필수 온습도·PM2.5·PWM·RPM 중 하나라도 무효이면 행 전체 제외. 30초 가열 자료는 가열 상태도 검사 |
| 온도 가열 실험 | 행과 나머지 정상 값은 유지하고 해당 칼럼만 빈칸 처리 |
| 연기 농도 실험 | PM·PWM·시각의 유효성 검사. JSONL의 무효 PM은 점검 기록과 함께 관리 |

결측을 0으로 대체하거나 보간하지 않았다. 평균과의 거리나 변화량만으로 관측값을 삭제하지 않고, 설정 범위와 센서 상태를 기준으로 판별하였다.

## 4. 연속 구간 분리

양수인 인접 측정 시각 차이의 중앙값을 대표 측정 간격으로 계산하였다. 다음 조건에서는 필터 구간을 분리하였다.

- 시간 역행 또는 동일 시각 반복
- 대표 측정 간격의 **1.5배를 초과**하는 측정 공백
- 흡기·배기 PWM 변경
- 온습도·PM 처리 구간에서 기록된 가열 상태 변경
- 오류·중복 행 제외로 인한 원본 행의 연속성 단절

온도 가열 자료의 센서 결측은 해당 신호의 필터만 초기화하였다. RPM 필터는 PWM 조합과 시간·행의 연속성을 기준으로 관리하고, 가열 상태만 바뀐 경우에는 이어서 적용하였다.

## 5. 후행 3표본 중앙값 필터

현재 값과 직전 두 개의 원본 관측값으로 중앙값을 계산하여 짧은 변동을 완화하였다.

```text
처리값[i] = median(원본값[i−2], 원본값[i−1], 원본값[i])
```

| 항목 | 적용 방식 |
| --- | --- |
| 온도·습도·PM2.5 | 연속 구간 내 후행 3표본 중앙값 적용 |
| 구간의 첫 두 표본 | 원값 유지 |
| 새 구간 | 필터 초기화 |
| PWM·가열 상태 | 평활화하지 않고 원값 유지 |
| 팬 제어 자료의 RPM | 평활화하지 않음 |
| 온도 가열 자료의 RPM | 일정 PWM 구간에서 후행 3표본 중앙값 적용 |

온도 가열 자료의 RPM은 해당 팬의 PWM이 0이거나 확인되지 않는 경우 평활화하지 않았다. 정지·재가동 구간도 원값을 유지하고, 처리 전 RPM은 `Intake_RPM_Raw[rpm]`·`Exhaust_RPM_Raw[rpm]`에 별도로 저장하였다.

## 6. 연기 농도 데이터 처리

### 6.1. PM2.5 상한 처리

PM2.5에 중앙값 필터를 적용한 **다음**, 500 µg/m³를 초과하는 값을 500으로 제한하였다.

```text
최종 PM2.5 = min(후행 3표본 중앙값, 500)
```

500 µg/m³는 분석용 상한값이다. JSONL 결과에는 원 측정값을 `PM2.5_Raw[ug/m3]`, 상한 적용 여부를 `PM_Capped[0/1]`로 구분하였다.

### 6.2. 시간축 정렬

| 구분 | 기준 |
| --- | --- |
| 전체 구간 | 기록 시작 기준으로 준비·연기 투입·회복 구간 유지 |
| 팬 시작 기준 | 실제 측정 시각에서 팬 ON 명령·이벤트 시각을 빼 경과 시간 계산 |
| PM500→PM50 비교 | 마지막 최고점 이후 PM2.5가 500 미만으로 5초 유지된 구간의 첫 표본을 0초로 설정 |
| PM50 도달 | PM2.5가 50 이하로 5초 유지된 구간의 시작까지 경과 시간 계산 |

팬 시작 이후 첫 표본이 0초보다 늦더라도 실제 시간을 유지하였다. 정확한 0초 또는 PM500 표본을 만들기 위한 보간은 하지 않았다. PM500→PM50 자료는 PM50 유지 확인 시점까지 추출하고, 평활화·상한 처리를 다시 적용하지 않았다.

2026-10-15~16 JSONL 측정의 A10·A11 오류 실험과 실패·미완료 재시도는 정상 실험에 이어 붙이지 않았다. 이 제외 기준은 해당 측정에 적용하였다.

## 7. 가열·냉각 데이터 연결

30초 가열 본 측정과 추가 냉각 자료는 다음 조건을 만족할 때 하나의 실험으로 연결하였다.

- 실험명·CSV 칼럼·흡기 및 배기 PWM 일치
- 냉각 메타데이터에 연속 측정 표시
- 본 측정 종료와 냉각 시작 이벤트의 시각 차이 5초 이내
- 냉각 측정 시각이 본 측정 이후이며, 냉각 구간의 `Heat_Load`가 0

경과 시간은 본 측정의 첫 유효 시각을 기준으로 계산하였다. 냉각 파일에 임의로 시간을 더하지 않고 실제 공백을 유지하였다. 가열 전·중·후 구간은 `Heat_Load[0/1]`로 구분하였다.

## 8. 전처리 결과 저장

전처리 결과는 실험별 CSV로 저장하고, 원본 파일은 유지하였다. 변경·제외된 값은 원본 행 번호, 칼럼, 처리 사유, 변경 전후 값과 함께 기록하였다. 전처리 전후 그래프로 평활화와 오류 처리 결과를 비교하였다.
